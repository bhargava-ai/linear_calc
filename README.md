# Simple Calculator

A beautiful, modern calculator built with React, TypeScript, and Tailwind CSS.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean and modern UI with gradient background
- Responsive design
- Smooth animations and hover effects

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The calculator will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Technologies Used

- React 18
- TypeScript
- Vite
- Tailwind CSS
